
# System Metrics Dashboard

A responsive frontend dashboard built with React, TypeScript, and CSS to monitor system metrics, CPU/memory usage, and active service statuses in real time.

## 🚀 Features
- **Real-Time Indicators:** Visual status progress bars for CPU, Memory, Disk IOPS, and Network I/O.
- **Service Management Table:** Interactive table listing running, degraded, and stopped Ubuntu system services.
- **Search & Filter:** Dynamic client-side filtering by service status and text query.
- **Type Safety:** Strongly typed components and data models using TypeScript interfaces.

## 🛠️ Tech Stack
- **Frontend Framework:** React
- **Language:** TypeScript
- **Styling:** Custom Modular CSS
